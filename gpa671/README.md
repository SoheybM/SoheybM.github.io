# GPA671 — Introduction to Artificial Intelligence

Public portfolio sources from my GPA671 coursework at **École de technologie supérieure (ÉTS Montréal)**, Fall 2026.

This directory is organized so that future laboratories can be added without changing the portfolio structure.

## Structure

- `lab-01/` — performance metrics, perceptrons and multilayer neural networks
- `lab-02/` — SVM, k-nearest neighbours and Gaussian Naive Bayes
- future work will follow the same pattern: `lab-03/`, `lab-04/`, etc.

Each laboratory contains:
- a short README describing the technical scope and selected results;
- a public source file containing the main implementations used in the experiments.

## Publication scope

These files are a **portfolio-oriented public extract**, not a republication of the graded assignments.

Teaching statements, course-provided datasets, full starter notebooks and proprietary/third-party resources are intentionally not redistributed. Some interface or scaffolding conventions in the code may originate from course starter material; the public files focus on the implementations and experiments completed during the laboratories.
